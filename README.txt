Norcon Construction — buildnorthern.ca
Upload everything in this folder to your web root.

  index.html            The site (all fonts, images, and logo inlined)
  robots.txt            Tells search engines to index the site; points to the sitemap
  sitemap.xml           Single-page sitemap
  assets/               Social share image + logo, referenced by absolute URL in
                        the page's meta tags. These must live at
                        buildnorthern.ca/assets/ or link previews will break.

After uploading:
  1. Verify the domain in Google Search Console, then submit
     https://buildnorthern.ca/sitemap.xml
  2. Create a Google Business Profile for each office (Sudbury, Timmins).
     This is the biggest driver of local search results.
  3. Test the link preview at https://www.opengraph.xyz/
